    From a webform or a spreadsheet

    Paste responses

    If collection runs through a webform, open its response sheet, select everything including the header row, copy, and paste it here. Column names are matched automatically and one row per idea is expected. Comma and tab separated files work too — drop them above like any other file.

    Where the record lives

    Pick a folder on your OneDrive and every submission you load is written into it as a file, straight away. That folder is the permanent record and it is what gets backed up. This browser only keeps a working copy, so clearing site data or moving to another machine loses nothing as long as the folder is set.
